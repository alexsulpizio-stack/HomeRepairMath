# Product Roadmap

## Phase 1 — Useful MVP

- Launch a clear homepage with the Repair vs. Replace calculator.
- Validate the scoring model with appliance-specific assumptions.
- Add dedicated, indexable pages for the highest-intent categories.
- Add About, Methodology, Privacy, Terms, and Contact pages before AdSense application.
- Add analytics and Search Console only after a public domain is connected.

## Phase 2 — High-value evergreen tools

Prioritize tools that combine meaningful homeowner value, commercial search intent, and low maintenance:

1. Washing machine repair vs. replace
2. Refrigerator repair vs. replace
3. Dishwasher repair vs. replace
4. Water heater repair vs. replace
5. HVAC repair vs. replace
6. Dryer repair vs. replace
7. DIY vs. hire-a-pro calculator
8. General project cost estimator
9. Appliance remaining-life estimator
10. Energy-efficiency payback calculator

## Phase 3 — Scalable landing pages

Build category pages from shared tool components, but keep every page materially useful and specific. Avoid templated pages that merely swap a product name.

Each page should add some combination of:

- item-specific lifespan assumptions
- common failure modes
- repair-cost thresholds
- safety considerations
- efficiency differences
- maintenance factors
- transparent formula explanation
- links to related tools

## Maintenance strategy

- Prefer static reference data checked periodically rather than live vendor feeds.
- Do not depend on current product prices for the core recommendation.
- Store assumptions in centralized data files so updates propagate across pages.
- Review lifespan/cost assumptions on a scheduled basis rather than publishing weekly content.
- Avoid news, deal tracking, and product-roundup content unless economics later justify the maintenance burden.
